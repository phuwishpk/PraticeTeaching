# IoT Interactive Learning

ห้องเรียน IoT แบบสด: ครูควบคุมเนื้อหาและกิจกรรมจากหน้าจอเดียว นักเรียนเข้าร่วมด้วย PIN 4 หลักจากมือถือ

## เริ่มใช้งาน

```bash
npm install
npm run dev      # โหมดพัฒนา
npm run build && node app.js   # โหมดใช้งานจริง
```

- นักเรียนเข้าที่ `/` แล้วกรอก PIN ที่แสดงบนจอครู (หรือสแกน QR)
- ครูเข้าที่ `/host` ได้โดยตรง

## ถ้าเซิร์ฟเวอร์รีสตาร์ตกลางคาบ

โหมดใช้งานจริงจะบันทึกสถานะห้องลงไฟล์ `.room-state.json` อัตโนมัติ เปิดเซิร์ฟเวอร์ใหม่แล้วห้องเดิมจะกลับมาทั้ง PIN รายชื่อ คะแนน และคำตอบ นักเรียนไม่ต้องทำอะไร หน้าจอไม่รีโหลดด้วยซ้ำ

```bash
ROOM_STATE_FILE=/data/room.json node app.js   # เปลี่ยนที่เก็บได้
```

## เอาขึ้นเว็บจริง

สิ่งที่ทำงานดีในเครื่องแต่พังบน hosting ถ้าไม่ตั้งค่า:

| ตัวแปร | ตั้งเป็น | ถ้าไม่ตั้งจะเป็นอะไร |
|---|---|---|
| `PUBLIC_ORIGIN` | `https://ชื่อเว็บของคุณ` | QR code ชี้เป็น `http://` นักเรียนสแกนแล้วเข้าไม่ได้ |
| `ROOM_STATE_FILE` | พาธบน persistent disk | ห้องหายทุกครั้งที่ deploy หรือเครื่องรีสตาร์ต |
| `TRUST_PROXY` | `1` เมื่ออยู่หลัง proxy | จำกัดอัตราผิดคน (ปล่อยไว้ปลอดภัยกว่าตั้งผิด) |

เซิร์ฟเวอร์จะเตือนเองตอนเริ่มทำงานถ้ายังไม่ได้ตั้ง และเขียนบอกทันทีถ้าดิสก์เขียนไม่ได้

**ต้องรันแค่ 1 instance** — สถานะห้องอยู่ในหน่วยความจำ ถ้าตั้ง autoscaling เป็น 2 เครื่อง นักเรียนจะกระจายไปคนละห้องคนละ PIN

**ต้องเป็นเซิร์ฟเวอร์ที่รันค้าง ไม่ใช่ Serverless** — ใช้ Render / Railway / Fly.io / VPS ส่วน Vercel และ Netlify Functions ใช้ไม่ได้ เพราะห้องอยู่ใน memory และใช้ SSE ส่งข้อมูลสด

### ตรวจสถานะระหว่างสอน

```bash
curl https://ชื่อเว็บของคุณ/api/room/health
```

```json
{ "ok": true, "students": 24, "streams": 25, "archivedRooms": 2,
  "persist": { "enabled": true, "ok": true }, "trustProxy": true }
```

`persist.ok` เป็น `false` เมื่อไหร่แปลว่าห้องกำลังไม่ถูกบันทึก — รีสตาร์ตเมื่อไหร่คะแนนหาย ใช้เป็น health check ของแพลตฟอร์มได้ด้วย (ไม่มี PIN อยู่ในนั้น จึงเปิดสาธารณะได้)

### แก้คะแนนหรือชื่อบนเว็บจริง

บน hosting ส่วนใหญ่แก้ `.room-state.json` ด้วยมือไม่ได้เพราะเข้าถึงไฟล์ไม่ได้ ให้ใช้ปุ่มในแผง PIN บนหน้าครูแทน (นำนักเรียนออก / เปิด-ปิดรับ / ย้อนกลับเข้าห้องเดิม)

## ย้อนกลับเข้าห้องเดิม

กด "เริ่มห้องใหม่" ไม่ได้ทำลายห้องเก่า แต่เก็บเข้าแฟ้มไว้ **1 วัน** (เก็บได้สูงสุด 8 ห้อง) ครูกดที่ป้าย PIN บนแถบบน แล้วเลือก "กลับเข้าห้อง" เพื่อย้อนกลับไปห้องไหนก็ได้ พร้อมรายชื่อ คะแนน และคำตอบเดิมครบ

- ห้องปัจจุบันจะถูกเก็บเข้าแฟ้มด้วย สลับไปมาระหว่างคาบเช้ากับคาบบ่ายได้
- นักเรียนที่เครื่องยังจำชื่อไว้จะกลับเข้าห้องเองอัตโนมัติ ไม่ต้องกรอกอะไรใหม่
- ห้องว่าง (ไม่มีนักเรียน) ไม่ถูกเก็บ และห้องที่เก่าเกิน 1 วันจะถูกลบทิ้ง
- แฟ้มนี้รอดการรีสตาร์ตเซิร์ฟเวอร์ด้วย เพราะบันทึกอยู่ในไฟล์เดียวกัน

โหมด `npm run dev` ไม่บันทึกลงไฟล์ จะได้เริ่มสดทุกครั้งที่แก้โค้ด

> ถ้า deploy บนแพลตฟอร์มที่ดิสก์หายเมื่อรีสตาร์ต (เช่น Render free tier) ต้องผูก persistent disk แล้วชี้ `ROOM_STATE_FILE` ไปที่นั่น ไม่งั้นไฟล์จะหายไปพร้อมเครื่อง

## กติกาของห้องเรียน

- **เข้าห้องได้เฉพาะตอนอยู่หน้า Lobby** พอครูเริ่มสอน ประตูจะปิดอัตโนมัติ ครูเปิดรับเพิ่มได้จากหน้า Lobby
- **ตอบได้ครั้งเดียวต่อคำถาม** และเฉพาะช่วงที่ครูเปิดกิจกรรมนั้นอยู่ หมดเวลาแล้วเซิร์ฟเวอร์จะปฏิเสธ
- **คะแนนลดตามเวลา** เต็ม 1000 ลดวินาทีละ 50 ต่ำสุด 500
- **อันดับบน Podium** เรียงตามคะแนนรวม ถ้าเท่ากันจึงตัดสินด้วยเวลารวมและเวลาที่ดีที่สุดของแต่ละคน
- นักเรียนที่ปิดแท็บกลับเข้ามาได้ด้วยชื่อเดิม ถ้าเครื่องหาย ครูกดชื่อในหน้า Lobby เพื่อคืนชื่อนั้นให้ได้
- **PIN แสดงบนแถบบนของหน้าครูตลอดเวลา** พร้อมสถานะว่าเปิดหรือปิดรับนักเรียน กดขั้น "เข้าห้องเรียน" เพื่อเปิดรับอีกครั้ง
